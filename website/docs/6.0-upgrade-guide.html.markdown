# Azure Provider

## Azure Provider Version 6.0

Version 6.0 of the Azure Provider is a major release that includes breaking changes and behavioural differences. This guide covers the most significant changes and explains how to upgrade from v5.x to v6.0.

When upgrading to version 6.0 of the Azure Provider, we recommend upgrading to the latest version of [Terraform](https://developer.hashicorp.com/terraform/install).

### Pinning your Provider Version

We recommend pinning the version of each Provider you use in Terraform. You can do this using the `version` attribute within the `required_providers` block:

```hcl
terraform {
  required_providers {
    azurerm = {
      source  = "hashicorp/azurerm"
      version = "=6.0.0"
    }
  }
}

provider "azurerm" {
  features {}
}
```

More information on [how to pin the version of a Terraform Provider being used can be found on the Terraform Website](https://developer.hashicorp.com/terraform/language/providers/requirements#require-providers).

## Breaking Changes in Resources

Please follow the format in the example below for listing breaking changes in resources:

```markdown
### `azurerm_example_resource`

* The deprecated `example_old_property` property has been removed in favour of the `example_new_property` property.
* The deprecated `example_property_with_no_replacement` property has been removed.
* The `example_property_with_changed_default` property now defaults to `NewDefault`.
```

---

### `azurerm_databricks_workspace`

* The deprecated `managed_disk_cmk_key_vault_id` property has been removed.
* The deprecated `managed_services_cmk_key_vault_id` property has been removed.
* The value of the `managed_resource_group_id` property is now normalized to the canonical resource ID format.

### `azurerm_databricks_workspace_root_dbfs_customer_managed_key`

* The deprecated `key_vault_id` property has been removed.

### `azurerm_storage_account`

* The deprecated `public_network_access_enabled` property has been removed.
