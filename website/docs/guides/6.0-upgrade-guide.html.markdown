# Azure Provider

## Azure Provider Version 6.0

Version 6.0 of the Azure Provider is a major release that includes breaking changes and behavioural differences. This guide covers the most significant changes and explains how to upgrade from v4.x to v6.0.

When upgrading to version 6.0 of the Azure Provider, we recommend upgrading to the latest version of [Terraform](https://developer.hashicorp.com/terraform/install).

### Pinning your Provider Version

We recommend pinning the version of each Provider you use in Terraform. You can do this using the `version` attribute within the `required_providers` block:

```hcl
terraform {
  required_providers {
    azurerm = {
      source  = "hashicorp/azurerm"
      version = "=6.0.0"
    }
  }
}

provider "azurerm" {
  features {}
}
```

More information on [how to pin the version of a Terraform Provider being used can be found on the Terraform Website](https://developer.hashicorp.com/terraform/language/providers/requirements#require-providers).
